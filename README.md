# Java Study Hub

[![Next.js](https://img.shields.io/badge/Next.js-14.2.5-black)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-18.3.1-blue)](https://reactjs.org/)

A Java learning web app scaffold focused on interview-ready topics, concept mapping, and searchable articles.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000`

## Project Structure

- `pages/` - Next.js page routes
- `components/` - Reusable UI components
- `data/` - Topic and article content
- `styles/` - Global styling

## Purpose

Build a Java-focused learning platform inspired by GFG and StackOverflow, with a question-driven content model, topic clusters, and SEO-friendly article pages.
